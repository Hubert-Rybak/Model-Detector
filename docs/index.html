    If you know which model wrote this text, label it. Labelled samples are kept in this browser only; export them to add to the repository's corpus/ and retrain.

    Method: character forensics plus a stylometric fingerprint (markdown habits, rhetoric, register, phrase lexicon) scored by hand rules and a naive-Bayes classifier trained on labelled samples in corpus/. Statistical token-choice watermarks (Google SynthID-Text, Anthropic's Claude watermark, OpenAI textGrain) are keyed and cannot be read without the provider's key; this page tells you whether such a watermark is expected for the attributed provider.
